# شروع سریع روی ویندوز و VS Code

مخزن محلی از قبل در `D:\osimertinib-cross-study-ml` کلون شده است.

1. ZIP آغاز پروژه را مستقیم داخل پوشه ریپازیتوری Extract کنید (بدون پوشه تو در تو). فایل‌های `README.md` و `.gitignore` قبلی را پاک یا جایگزین نکنید.
2. ترمینال VS Code را باز کنید و دستور زیر را اجرا کنید:

   ```powershell
   cd D:\osimertinib-cross-study-ml
   python --version
   python scripts\01_inspect_gse193258.py
   ```

3. اگر Python با دستور `python` شناسایی نشد، `py --version` و سپس `py scripts\01_inspect_gse193258.py` را آزمایش کنید.
4. اگر دانلود از GEO در شبکه شما محدود بود، لینک فایل اصلی در `docs/RESEARCH_PLAN.md` و پیام خطا نشان داده می‌شود؛ می‌توانید فایل را از صفحه GEO دستی بگیرید و با همان نام در `data/raw/` بگذارید، سپس اسکریپت را دوباره اجرا کنید.
5. در خروجی `results/`، فایل‌های `GSE193258_dataset_report.json` و `GSE193258_table2_preview.csv` ایجاد می‌شوند. **جدول فقط پیش‌نمایش ابعاد داده است** و هنوز نمونه‌های قابل مقایسه DTP و Resistant را نشان نمی‌دهد.
6. برای بررسی فایل‌های جدید: `git status`؛ تا وقتی داده‌ها/برچسب‌ها تأیید نشده‌اند نتایج را در مقاله گزارش نکنید.
